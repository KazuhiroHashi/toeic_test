# 屋号(Bridge AI)で App Store に出すまでの手順

App Store の販売者名は、個人アカウントのままだと `Kazuhiro Hashino` になる。
**一度公開すると、アプリ情報の収集サイトやアーカイブに永久に残り、あとから消せない。**
屋号で出すには、Apple のアカウントを個人(Individual)から組織(Organization)に
移す必要がある。その手順。

**所要:1〜3か月。**費用は0円(Developer Program の年会費以外にかからない)。

屋号は **`Bridge AI`** で確定。開業届・D-U-N-S・Apple・銀行のすべてでこの表記を使う。
1文字でも違うと照合で落ちる。

---

## 全体の流れ

```
1. 開業届(税務署)          即日・0円      ← 屋号がここで初めて公式なものになる
2. 副業申請(勤務先)         数日
3. D-U-N-S番号(TSR)        約2週間        ← 開業届の控えが要る
4. 組織移行の申請(Apple)     約2週間〜
5. 税務フォームの再提出       最長2か月      ← ここが一番詰まる
        ↓
   App記録の Developer 名が Bridge AI になる → リリースできる
```

3以降は待ち時間なので、**その間にアプリ側の準備(App記録・課金アイテム・
ビルド・TestFlight・審査提出)を並行して進める。**審査提出時に「手動でリリース」を
選べば、承認済みの状態で待機できる。

---

## 1. 開業届を出す — **済(2026年8月・屋号 `Bridge AI` で提出)**

**e-Tax で出すこと。**紙で出すと証明にならない。

2025年1月から、税務署は控えに収受印(受付印)を押さなくなった。紙で持ち込んでも
押印付きの控えはもらえず、TSR や Apple に出す証明として使えるか不確実。
e-Tax の受信通知は電子的な正式記録なので、これが一番確実。

### 必要なもの

- マイナンバーカード(4桁の暗証番号)
- NFC対応のスマホ(iPhone 7 以降)

### 手順

1. [e-Tax](https://www.e-tax.nta.go.jp/) で「マイナンバーカード方式」のアカウントを作り、
   利用者識別番号(16桁)を取得する。過去に e-Tax で確定申告していれば、その番号でよい
2. 「個人事業の開業・廃業等届出書」を作成して送信する

慣れていなければ [freee開業](https://www.freee.co.jp/kaigyou/) や
[マネーフォワード クラウド開業届](https://biz.moneyforward.com/establish/) を使う。
質問に答えるだけで書類ができ、e-Tax 送信まで案内してくれる。無料。

### 書く内容

| 欄 | 入れるもの |
|---|---|
| 納税地 | 自宅住所。**App Store Connect に登録した住所と完全に一致させる** |
| 職業 | `ソフトウェア業` |
| **屋号** | **`Bridge AI`** ← 空欄で出すと目的を達成できない。最重要 |
| 届出の区分 | 開業 |
| 開業日 | 任意(提出日から1か月前後) |
| 所得の種類 | 事業所得 |
| 事業の概要 | `モバイルアプリケーションの開発・販売、およびWebコンテンツの制作・販売` |
| 給与等の支払の状況 | なし |

### 終わったら

**e-Tax のメッセージボックスに入る『受信通知』を PDF で保存・印刷する。**
手順3で TSR に提出するのがこれ。

### あわせて検討

- **青色申告承認申請書**を同時に出せる。期限は開業日から2か月以内。
  最大65万円の控除が使える代わりに複式簿記の記帳義務が付く。副業規模なら白色から
  始めてもよい
- 開業届を出しても勤務先に通知は行かない。知られる経路は主に住民税なので、
  確定申告のときに住民税を「自分で納付(普通徴収)」にする

## 2. 勤務先に副業申請

勤務先の様式に従う。**年収見込みの書き方だけ注意する。**

```
年間30万円程度を見込む(新規事業のため実績がなく、大きく下振れする可能性があります)
```

- 少なく申告して超過するより、多めに書いて下回るほうが社内的に無害。
  申告10万→実際100万だと再申請になりうる
- ただし過大に書くと「本業に影響するのでは」と見られる。30万円程度は
  小遣い規模として説明しやすい
- 様式に「金額が変わったら再申請」の規定があるか確認し、あればその閾値の少し下を書く

無名の個人開発アプリの初年度は数千円〜数万円で終わることが珍しくない。
楽観的な数字を書く必要はない。

---

## 3. D-U-N-S 番号を取る

D&B(Dun & Bradstreet)が発行する国際的な事業者番号。日本の窓口は
東京商工リサーチ(TSR)。**Apple 経由なら無料。**

### 手順

1. [Apple の D-U-N-S 検索・申請ページ](https://developer.apple.com/enroll/duns-lookup/) を開く
2. まず既存の番号がないか検索する。無ければ申請フォームに進む
3. 事業者名 `Bridge AI`、住所(開業届と同じ)、電話番号を入力
4. TSR から確認メールが来る。**6項目程度の質問に答え、開業届の控え(受信通知)を添付する**

所要は約2週間。実例では申請から登録完了まで12日ほど。

### 引っかかりどころ

- **事業所名・住所は、あとで Apple に入れる値と完全に一致させる。**
  全角/半角、番地の書き方が違うだけで照合に失敗する
- **自宅が事業所として D&B の企業情報データベースに載る。**
  「個人名を隠す」目的は達するが、「自宅住所が商用データベースに載る」という
  別の露出が生まれる。これは避けられない
- Apple の申請は、普段使っている Apple ID で通す

---

## 4. Apple に個人→組織の変更を申請

[Apple Developer のサポート窓口](https://developer.apple.com/contact/) から依頼する。

### 引っかかりどころ

- **申請フォームが法人前提の作りで、個人事業主だとエラーになることがある。**
  その場合はサポートに「個人事業主として組織アカウントに登録したい」と
  明示的に伝えるのが早道
- **在職証明書を求められることがある。**個人事業主の場合は自分で作成して提出する
- **独自ドメインのWebサイトと、そのドメインのメールアドレスを求められる事例がある。**
  → `bridge-ai-tokyo.com` と `contact@bridge-ai-tokyo.com` は用意済み
- **移行中は証明書ポータル(Certificates, Identifiers & Profiles)が使えない。**
  アプリのアップロードや審査提出は継続できる

所要は約2週間。D-U-N-S の情報を Apple 側で確認するのに2〜3営業日かかることもある。

## 5. 税務フォームの再提出

**ここが一番詰まる。**組織になると税務フォームが法人用(W-8BEN-E)に切り替わり、
個人で提出済みの W-8BEN は無効になる。

App Store Connect の税務フォームが個人事業主をうまく扱えず、Apple とのやり取りに
**約2か月**かかったという報告がある。時間を見ておくこと。

### あわせてやり直しになるもの

1. **銀行口座** — 組織名義で登録し直す。楽天銀行の口座名義が個人名のままだと
   通らない可能性があり、屋号付き口座の開設が必要になるかもしれない
2. **有料アプリ契約** — 再同意が要る
3. **小規模事業者プログラム** — 引き継がれるか不明。再申請になる可能性がある
4. **移行開始前の売上の振込先** — 移行完了前の売上は「移行開始時点で有効な口座」に
   振り込まれる。口座を変えるなら移行を始める前に

---

## 完了の確認

移行が完了すると、**既に公開しているアプリも含めて**販売者名が `Bridge AI` に変わる。
反映にはラグがある。

「組織移行したのに販売者名が個人名のままだった」という報告が Apple のフォーラムに
あるので、切り替わらない場合はサポートに個別依頼する。

---

## やらないこと

- **EU での配信を有効にしない。**DSA の規定により、トレーダーとして
  氏名と住所が App Store 上で公開される。他の174の国・地域には出せる。
  あとから追加できる
- **商標出願は急がない。**`Bridge AI` 単独の商標登録は J-PlatPat で確認した限り
  存在しない。事業が形になってから検討すれば足りる(1区分で出願12,000円+登録32,000円)
