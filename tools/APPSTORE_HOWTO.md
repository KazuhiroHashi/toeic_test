# App Store で売る手順(iOS)

> Mac のターミナルと Xcode で作業します。コマンドは1行ずつコピペして Enter。

この問題集を iPhone アプリとして App Store に出すための手順です。
中身は Web 版とまったく同じソースを使うので、**問題を直せばアプリ版にも同じように反映されます。**

---

## 先に知っておくこと(重要)

### 1. アプリ名に「TOEIC」を使うときの作法

`TOEIC` は ETS の登録商標ですが、**第三者の対策アプリが名称に使うのは App Store で一般的な運用**です。
実際に「トレーニング TOEIC® test」「はじめてのTOEIC®問題集」など、公式でないアプリが多数公開されています。

守るべきことは2つだけです。**これを外すと審査や権利者からの申し立ての対象になります。**

1. **必ず `®` を付ける** — `TOEIC® 総合問題集`。`TOEIC 総合問題集` と裸で書かない
2. **ETS 所定の免責文を表示する** — アプリ内(フッターに常時表示済み)と、App Store の説明文の両方に入れる

```
TOEIC®はエデュケーション・テスティング・サービス(ETS)の登録商標です。
この製品はETSの検討を受けまたはその承認を得たものではありません。
```

`bash tools/build_app.sh` は、この免責文がフッターから消えていたら**エラーで止まります**。

> 「公式」「認定」「オフィシャル」と受け取れる表現は使わないでください。そこが境界線です。

### 2. 「Webサイトを包んだだけ」は落ちます

Apple のガイドライン 4.2 は、ブラウザで見るのと変わらないアプリを認めていません。
2025年後半から2026年にかけて、この理由でのリジェクトが増えています。

**この設定では、次の3つで「アプリでしかできないこと」を作ってあります。**審査でもここを説明します。

1. **完全オフライン** — 音声4,252本(134MB)と写真60枚をアプリに同梱。電波の無い地下鉄でもリスニングができる
2. **マナーモードでも音が鳴る** — Safari は本体がマナーモードだと無音になる。アプリ版は `AVAudioSession` で回避する
3. **画面を消しても音声が続く** — ポケットに入れたまま聞ける

2と3は `node tools/setup_ios.js` が自動で入れます(手順6)。

## 手順

### 1. Xcode を入れる

Mac の App Store で「Xcode」を検索してインストール(無料・十数GB・時間がかかります)。
終わったら一度起動して、ライセンスに同意します。

```bash
xcode-select --install
sudo xcodebuild -license accept
```

### 2. リポジトリを最新にする

```bash
cd ~/Documents/toeic_test && git pull origin main
```

### 3. 必要なものを入れる

```bash
npm install
```

> **CocoaPods は要りません。**Capacitor 8 から iOS は Swift Package Manager が既定になり、
> Xcode が自動で依存を解決します。追加のインストールは不要です。
>
> Node は 22 以上が必要です(`node -v` で確認)。

### 4. アプリに詰める中身を作る

```bash
bash tools/build_app.sh
```

`写真 60/60  音声 4252/4252` と出て `OK:` で終われば成功です。
**ここで欠けが出たら止まります。**オフラインが売りなので、1つでも足りないまま進めないためです。

### 5. iOS のプロジェクトを作る

```bash
npx cap add ios
```

`ios/` というフォルダができます。

### 6. iOS 側に手を入れる(マナーモード対策・背景再生)

```bash
node tools/setup_ios.js
```

`✓ AppDelegate.swift` と `✓ Info.plist` が出れば成功です。**この手順は5のあと1回だけ**でかまいません。

### 7. アイコンを作って置く

```bash
python3 tools/make_app_icon.py
```

`assets/appicon/icon-1024.png` ができます。これを Xcode に入れます。

1. `npx cap open ios` で Xcode が開く
2. 左の一覧で `App` → `Assets` → `AppIcon` を選ぶ
3. 1024×1024 の枠に `assets/appicon/icon-1024.png` をドラッグ

> 自分でデザインした画像を使う場合も、**1024×1024・透過なし・角丸なし**(角丸は iOS が付けます)。

### 8. 署名の設定

Xcode で `App` を選び、`Signing & Capabilities` タブへ。

1. `Automatically manage signing` にチェック
2. `Team` に、登録した Apple Developer のチームを選ぶ
3. `Bundle Identifier` が `com.eigoscoremogi.toeic` になっていることを確認

> この ID は後から変えられません。変えたい場合は先に `capacitor.config.json` の `appId` を直し、`ios/` を消して手順5からやり直します。

### 9. 実機で動かして確認する

iPhone を Mac に繋ぎ、Xcode 左上の実行先を自分の iPhone にして ▶︎ を押します。

**必ず次の4つを確認してください。**

1. 機内モードにして、リスニングが最後まで再生できる(オフライン確認)
2. **本体をマナーモードにしても音が鳴る**
3. 再生中に電源ボタンで画面を消しても音が続く
4. 10セットすべてが最初から開ける(合言葉の入力欄が出ない)

### 10. スクリーンショットを撮る

必要なのは **6.9インチ iPhone の 1320 × 2868 ピクセル**だけです。
Apple がこれを縮小して他の機種の表示に使うので、小さい機種のぶんは要りません。

Xcode のシミュレータで iPhone 16 Pro Max を選び、`command + S` で保存します。
3〜5枚。おすすめは次の画面です。

1. ホーム(10セットが並んでいるところ)
2. Part 1(写真+選択肢)
3. Part 7(長文)
4. 結果画面(予想スコアが出ているところ)
5. 解説画面

> PNG または JPEG、sRGB、透過なし。**1ピクセルでも違うとアップロードを弾かれます。**

### 11. App Store Connect に登録する

https://appstoreconnect.apple.com で「マイApp」→「+」→「新規App」。

| 項目 | 入れるもの |
|---|---|
| 名前 | TOEIC® 総合問題集(**® を必ず付ける**) |
| プライマリ言語 | 日本語 |
| バンドルID | 手順8で使ったもの |
| SKU | eigo-score-mogi-1 など(自分用の管理番号) |
| カテゴリ | 教育 |
| 年齢制限 | 4+ |

**プライバシー**は「データを収集しません」を選びます(このアプリは通信も送信もしません)。
ただし**プライバシーポリシーのURLは必須**なので、1ページ用意してください。
GitHub Pages にファイルを1つ置けば足ります(用意が必要なら言ってください、作ります)。

**輸出コンプライアンス**は、手順6で `ITSAppUsesNonExemptEncryption = false` を入れてあるので聞かれません。

### 12. アップロードして提出

Xcode で実行先を `Any iOS Device (arm64)` にして、メニューの `Product` → `Archive`。
終わったら `Distribute App` → `App Store Connect` → `Upload`。

App Store Connect 側に反映されたら(処理に10〜30分)、そのビルドを選んで「審査へ提出」。

### 13. 審査メモに必ず書くこと

提出画面の「**App Review に関する情報 → メモ**」に、次をそのまま貼ってください。
ガイドライン 4.2 でのリジェクトを避けるための説明です。

```
本アプリは、当方が全て自作したオリジナルの英語模擬試験問題集です(2,000問)。

ブラウザ版では実現できない、以下のネイティブ機能を備えています。

1. 完全オフライン動作
   音声4,252ファイル(約134MB)と画像60点をアプリ内に同梱しており、
   ネットワーク接続が一切ない環境(地下鉄、機内など)でも
   リスニング試験を含む全機能が利用できます。通信は一切行いません。

2. マナーモード時の音声再生
   AVAudioSession を playback カテゴリに設定しているため、
   端末がマナーモードでもリスニング音声が再生されます。
   Safari ではマナーモード時に無音となり、学習が成立しません。

3. 画面ロック中の音声継続再生
   UIBackgroundModes(audio)により、画面を消した状態でも
   リスニング音声が継続します。

本アプリはユーザーデータを一切収集・送信しません。
アカウント登録も不要で、審査用のログイン情報はありません。

商標について:
TOEIC はエデュケーション・テスティング・サービス(ETS)の登録商標です。
本アプリは ETS の検討・承認を受けたものではありません。
名称および説明文では登録商標であることを示す (R) を付して表示し、
アプリ内フッターに ETS 所定の免責文を常時表示しています。
公式・認定・提携等を示唆する表現は一切使用しておりません。
```

> **App Store の説明文にも、同じ免責文を必ず入れてください。**アプリ内だけでは足りません。

## 問題を直したあとの反映

Web 版とアプリ版は同じソースなので、直したら次を実行するだけです。

```bash
bash tools/build_app.sh && npx cap sync ios
```

そのあと Xcode で Archive → Upload。**バージョン番号を上げるのを忘れずに**(Xcode の `General` → `Version`)。

> Web 版(GitHub Pages)は `bash tools/sync.sh` のままです。アプリ版とは別に反映されます。
> **アプリは審査があるので、直してもすぐには届きません**(通常1〜3日)。急ぎの修正は Web 版のほうが早いです。

## 課金をどうするか

いまの設定は **買い切り(アプリ自体に値段を付ける)** 前提です。
`www/app-build.js` の `unlockAll: true` により、10セットすべてが最初から開きます。

**アプリ内課金にする場合**は次が必要になります。

1. `unlockAll` を false にして、無料で遊べるセットを決める
2. StoreKit の実装(購入・購入の復元)
3. App Store Connect で App内課金アイテムを作る
4. Sandbox アカウントでの購入テスト

> **注意:** 「アプリは無料で配り、合言葉を note で売る」はできません。
> ガイドライン 3.1.1 で、アプリ内の機能解放は Apple の課金を通すことが義務づけられており、
> 外部の購入手段へ誘導することは禁止されています。確実にリジェクトされます。

## 困ったとき

| 症状 | 対処 |
|---|---|
| `npx cap add ios` で失敗 | `npm install` が終わっているか確認。`bash tools/build_app.sh` を先に実行 |
| `node tools/setup_ios.js` が「ios/ がありません」 | 手順5をやっていない |
| Xcode で `Signing for "App" requires a development team` | 手順8の Team が未選択 |
| 実機で音が出ない | マナーモードではなく、手順6を実行したか確認。`ios/App/App/AppDelegate.swift` に AVAudioSession があるか見る |
| アプリの容量が大きいと言われる | 音声134MB があるため200MB前後になります。App Store の上限(4GB)には十分収まります |
| 審査で 4.2 リジェクト | 手順13のメモを入れたか確認。入れて再提出し、それでも落ちたら返信で1〜3を具体的に説明する |
