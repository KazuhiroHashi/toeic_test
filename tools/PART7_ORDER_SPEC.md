# Part 7 シングルパッセージの並び順を本番に合わせる作業

あなたは市販レベル(有料販売)のTOEIC模試の作問担当。**指定された1つのファイルだけ**を直す。

## 何が問題か

いまのシングルパッセージ10文書は、設問数が 3,3,3,2,2,3,3,4,3,3 のようにばらけていて、
さらに**テキストメッセージのやり取りが147番の一発目**に来ている。本番ではこうならない。

## 本番の構成(これに合わせる)

シングルパッセージは147〜175番の29問。**設問数は必ずこの並びになる。**

1. 文書1 … **2問**(147-148)
2. 文書2 … **2問**(149-150)
3. 文書3 … **2問**(151-152)
4. 文書4 … **2問**(153-154)
5. 文書5 … **3問**(155-157)
6. 文書6 … **3問**(158-160)
7. 文書7 … **3問**(161-163)
8. 文書8 … **4問**(164-167)
9. 文書9 … **4問**(168-171)
10. 文書10 … **4問**(172-175)

合計 2×4 + 3×3 + 4×3 = **29問**。

## 文書種別の置き方

- **前半(2問の4つ)は短い実務文書**にする。お知らせ / 広告 / 社内メモ / 短いEメール / 求人 / 様式 など。
- **テキストメッセージのやり取りは2問セットのどこか**(文書2〜4のいずれか)に置く。**文書1にはしない。**
- **オンラインチャット(3人以上)は後半の4問セット**(文書8〜10のいずれか)に置く。人数が多く長いので、本番でも設問数が多い位置に来る。
- 記事・ウェブページ・手紙など読ませる文書は、3問または4問の位置に置く。

## 本文の長さも設問数に合わせる

本番では、設問が多い文書ほど長い。いまは全部170〜250語で揃っているので、**位置に応じて調整する。**

- 2問の文書 … **90〜140語**(短くする。冗長な段落を削る)
- 3問の文書 … **150〜200語**
- 4問の文書 … **220〜280語**(段落を足して情報量を増やす)

## 手順

1. 対象ファイルを Read する。
2. シングル10文書(`passages` が1つのもの)を、上の構成に**並べ替える**。
3. 設問数を合わせる。
   - **減らすとき**:いちばん出来の弱い設問を落とす。場所・目的を問う基本設問は残す。
   - **増やすとき**:本文に根拠がある設問を新しく書く。根拠が足りなければ**本文に段落を足してから**設問を作る。
4. 本文の長さを上の目安に合わせる。
5. `id` を並び順に振り直す。先頭が `-01`、10番目が `-10`(接頭辞は元のまま。例 `s7p7-01`)。
6. **ダブル(`-11`,`-12`)とトリプル(`-13`,`-14`,`-15`)は一切触らない。**配列の後ろにそのまま残す。
7. `node --check <対象ファイル>` で構文確認する。

## 守ること(絶対)

- **シングルの合計は必ず29問。**文書は10、ダブル2セット10問、トリプル3セット15問、総計54問。
- `answer` は選択肢配列の添字(0=A)。**設問を足したら A/B/C/D が均等に散るように調整する。**
- 日本語の `explanation`(解説)と `translation`(訳)を全問・全文書に付ける。強調は『』。Markdownの `**` は使わない。
- 解説で選択肢を指す (A)(B)(C)(D) は、必ず実際の配列位置と一致させる。
- 本文を削ったら `translation`(全訳)も必ず同じだけ削る。段落を足したら訳も足す。**本文と訳がずれてはいけない。**
- 【最重要】**ある設問の答えが、同じ文書の他の設問の文・選択肢から推測できてはならない。**
  特に場所・目的・業種を問う設問の答えの語を、他の設問の選択肢に入れない。書き終えたら全設問を読み返して確認する。
- 正解は本文の言い換え。本文の語句をそのまま含む誤答を各問に1つ入れる。
- 正解が2つあり得る問題・正解が無い問題を作らない。必ず自分で解き直す。
- 固有名詞・場面は**既存のものをそのまま使う**(他セットとの重複チェック済みのため、新しい会社名や人名を勝手に作らない)。
  段落を足すときも、その文書に既に出ている固有名詞の範囲で書く。

## 最終メッセージ

短く。並べ替え後の「設問数の並び」と「文書種別の並び」を1行ずつ、それに増減した設問数だけ。**本文は貼らない。**
