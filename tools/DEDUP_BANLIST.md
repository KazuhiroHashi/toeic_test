# 題材の重複回避(禁止リスト+ドメイン指定)

セット1〜6で題材が重複しないようにするための指示。**新しく作る問題は、下の「禁止題材」を一切使わず、割り当てられた「担当ドメイン」を中心に、具体的で新規性のある場面**にすること。設問形式(図表・意図・3人会話・クロスリファレンス等)の要件は AGENT_SPEC.md 通りに満たす。

## 禁止題材(既存セットで頻出。会話・トーク・文書のいずれでも使わない)
- レンタカー/カーレンタルの車種アップグレード・乗り捨て料金
- 薬局での処方薬の受け取り・ジェネリック切替
- IT/ヘルプデスクへのログイン不可・VPN接続不可・パスワード再設定
- フェリー/電車/バスの時刻表を使った便選び(図表)
- ケータリングの注文変更(特にサーモン→チキン)・提供人数の確認
- 図書館の開館時間延長・セルフ貸出機・改装休館
- 植物園/ワイナリー/チョコレート工場などの見学ガイドツアー
- コミュニティセンター/公民館の開所式スピーチ
- 製品ローンチ・新製品発売の工程表/スケジュール遅延(図表)
- 語学学習アプリの料金プラン広告(NOT問題)
- オフィスの高層ビル/タワーへの移転案内
- 雑誌の未着・購読延長のお詫び状
- 経費精算システム導入の社内メモ/お知らせ
- ジム/フィットネスクラブの会員プラン・プール清掃/張り替えによる閉鎖
- 家具店の週末クリアランスセール・家具の早期配送
- 求人応募と応募者要件の突合(ウェブ開発者・店長など)
- コワーキングスペースの月額プラン選択
- スタンディングデスク/オフィス家具の在庫切れ・色変更
- 駐車場/ガレージの料金表(図表)・保守による閉鎖
- ニュースレター登録数の分析(図表)
- 印刷会社の名刺/チラシ/ポスター注文と割引計算

## 担当ドメイン(各セットはこの業界・文脈を中心にする=セット同士が自然に分かれる)
- **セット4**: 製造/工場、物流/倉庫/配送、出版/新聞、不動産/建物管理、保険、農業/食品生産・卸
- **セット5**: 医療/歯科/クリニック、教育/大学/オンライン講座、環境/リサイクル/再生エネルギー、園芸/造園、写真/映像制作
- **セット6**: 金融/銀行/会計、放送/メディア/広報、建設/建築/内装、アパレル/小売、飲食店・カフェの経営、劇場/コンサート/イベント運営

## 共通の注意
- 同一セット内でも題材を多様にし、上記ドメイン内で場面を散らす(例:製造なら「工場見学の安全説明」「部品供給業者との納期調整」「設備更新の社内周知」「品質検査の結果報告」など別々に)。
- 図表問題の図表も、禁止リストの図表(時刻表・駐車料金・登録数・印刷見積)とは別種にする(例:座席表、フロア案内図、製品仕様比較表、経費内訳、在庫一覧、シフト表 等)。
- 固有名詞(会社名・人名・地名)も既存セットと重複させない。
