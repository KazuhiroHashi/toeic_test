# セット7〜10 作業仕様(上級レベル)

既存6セットより **もう一段階難しい** 問題集を作る。あなたは市販レベル(有料販売)のTOEIC模試の作問担当。**指定された1つのデータファイルだけ**を新規に作る。

## 狙うレベル

既存セット(公式問題集〜700点クラス中心)より1段上。**800〜900点を狙う人向け**。

1. **標準(700点クラス):全体の 30%**
2. **上級(800点クラスの問題集レベル):全体の 50%** ← ここが中心
3. **難問(900点保持者でも落としうる):全体の 20%**

やさしめ(600点で解ける)問題は入れない。ただし**奇問・悪問も作らない**。本番に出てもおかしくない範囲で最上位を狙う。

## 難しさの作り方(ここを間違えないこと)

**難単語を並べて難しくするのは禁止。**900点が落とすのは語彙力ではない。次で作る。

- **関係詞** — `whose` / 前置詞+関係代名詞(`in which` / `for which` / `by which`)/ 関係副詞と関係代名詞の使い分け / `what` と `that` / 連鎖関係詞(`who we believe is`)/ 非制限用法
- **構造がつかみにくい** — 挿入句・同格で主語と動詞が大きく離れる / 分詞構文の意味上の主語 / 否定語句の文頭倒置 / `so`/`neither` の倒置 / 相関接続詞の並列 / 準動詞の主語
- **場面がイメージしづらい** — 指示語・代名詞が何を受けるか、省略された語は何かを読まないと決まらない
- **一見どれも入りそう** — 4つとも文法的には成立するが、文脈上1つしか成り立たない
- **情報処理量** — 読む量・突き合わせる箇所を増やす(Part 6/7)

語彙で難しくする場合も、**TOEICに実際に出る業務語彙の範囲内**にとどめる。学術語・日常業務で使わない語は使わない。

## 手順
1. `/workspace/toeic_test/tools/AGENT_SPEC.md` を Read し、そのパートの必須仕様(問題数・形式・データ構造)を確認する。
2. `/workspace/toeic_test/tools/DEDUP_BANLIST.md` を Read する。
3. **既存セットの同じパートを1つ Read し、題材・固有名詞・場面が重複しないようにする**(例: セット7の part5 を作るなら `data/part5.js` を読む)。編集は禁止、参照のみ。
4. 対象ファイルを新規作成する。
5. `node --check <対象ファイル>` で構文確認する。
6. 最終メッセージは短く:レベルの内訳と、難問にした箇所の狙いを5行以内。ファイル本文は貼らない。

## 守ること(絶対)
- `answer` は選択肢配列の添字(0=A)。**正解位置を A/B/C/D おおよそ均等**に散らす。
- 日本語の `explanation`(解説)と `translation`(訳)を全問に付ける。強調は『』を使い、Markdownの `**` は絶対に使わない。
- 解説で選択肢を指す記号(A)(B)(C)(D)は、必ず実際の配列位置と一致させる。
- 【最重要】1つの音声・文書に複数の設問が付く場合、**ある設問の答えが他の設問の文・選択肢から推測できてはならない。**書き終えたら自分で全設問を読み返して確認する。
- 正解が2つあり得る問題・正解が無い問題を作らない。書いたら必ず自分で解き直す。
- 固有名詞・場面が既存セットと重複しないこと。

## パート別の要点

### Part 1(6問)
無人の写真(状態を表す受動態)を2枚、複数人の写真を2枚含める。誤答は `being 過去分詞`(進行中の動作)と `have been 過去分詞`(状態)の取り違えを狙う。

### Part 2(25問)
16問目以降は間接応答・変化球を厚くする。上級セットなので、**質問に直接答えない応答**を10問以上入れる(「分かりません」「担当者に聞いて」「その予定は変わった」など)。

### Part 3(13会話39問)
3人の会話×2、図表問題×2、意図問題×2を含める。会話は言い直し・言いよどみ・話題転換を入れて、聞き流すと取り違える作りにする。

### Part 4(10トーク30問)
図表問題×2を含める。電話メッセージ・アナウンス・広告・会議・スピーチ・交通情報など文脈を散らす。

### Part 5(30問)
出題比率は本番どおり:語彙10・品詞6・動詞の形5・前置詞/接続詞5・関係詞代名詞3・比較/仮定法/倒置1。
**難問6問**を上の「難しさの作り方」から作る(関係詞3・構造把握2・文脈依存1が目安)。

### Part 6(4文書16問)
空所の3分の2以上を、前後の文脈を読まないと決められないものにする。文挿入問題(各文書1問)のうち2問は指示語・代名詞の対応で決まる難しめにする。文書は130〜180語。

### Part 7(15文書54問)
- **正解は必ず本文の言い換え。**本文の語句をそのまま含む誤答を各問に1つ入れる。
- 推論問題(suggested / implied / most likely)を12問以上。NOT問題3問、意図問題2問、語彙問題3問(基本語の多義:address / figure / hold / draw / issue など)。
- **【最重要】ダブル・トリプルの作り込み。**ダブル5問中3問以上、トリプル5問中4問以上を、2つ以上の文書を突き合わせないと解けない設問にする。
  - トリプルは**3文書すべてを読まないと全体像がつながらない構成**にし、3文書目で初めて事情が判明する設問を各セット2問入れる。
  - 突き合わせの型:料金表×申込内容→支払額 / 締切×送信日→間に合うか / 条件一覧×経歴→該当区分 / 変更通知×元の予定→最終的にどうなったか。
  - 文書間をつなぐ手がかりは**同じ語を繰り返さず言い換える**(`the Springfield branch` ↔ `our northern location`)。対応関係に気づくこと自体を問う。
- 文書はシングル170〜250語、ダブル・トリプルは各文書130〜200語。
