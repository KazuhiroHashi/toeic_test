# アプリ内課金で売る手順(セット1無料 / セット2〜10を有料)

売り方はこうなります。

```
お客さん → アプリを無料でダウンロード → セット1(200問)を試す
        → アプリ内の「すべて解放する」を押す → Apple が決済
        → セット2〜10 が開く(1回きりの支払い。以後ずっと有効)
```

**合言葉はアプリでは使いません。**Apple のガイドライン 3.1.1 で、アプリ内の機能を
Apple 以外の支払いで解放することが禁じられているためです。合言葉は Web 版だけの仕組みです。

---

## 段階0:有料App契約(いちばん時間がかかる。今すぐ始める)

**これが「有効」になるまで、課金アイテムを作ることすらできません。**
口座の確認に数日かかることがあるので、他の作業より先に着手してください。

App Store Connect → **ビジネス**(Business)を開き、3つとも完了させます。

1. **有料Appの契約に同意** — Account Holder(ご本人)のアカウントでしか操作できません
2. **銀行口座を登録** — 売上の入金先
3. **税務フォームを提出** — 日本の税務情報と、米国向けの税務情報の両方

状態が「**有効**(Active)」になれば通過です。

### あわせて:小規模事業者プログラム

手数料が **30% → 15%** になります。年間売上100万ドル未満が対象。
[申請ページ](https://developer.apple.com/jp/app-store/small-business-program/)から別途申請が必要で、適用は原則として翌月からです。

¥1,980 の場合、手取りが 1,386円 → **1,683円**。1本あたり約300円違います。

## 段階1:課金アイテムを作る

App Store Connect → 対象のApp → **App内課金**(In-App Purchases)→ **+**

| 項目 | 入れるもの |
|---|---|
| 種類 | **非消費型**(Non-Consumable)← 一度買えば永久に有効 |
| 参照名 | 全セット解放(自分用の管理名。お客さんには見えません) |
| **製品ID** | `com.eigoscoremogi.toeic.unlockall` |
| 価格 | ¥1,980 |

> **製品IDは1文字でも違うと購入画面が出ません。**アプリ側は
> `tools/build_app.sh` の中の `productId` を見ています。変えるなら両方そろえてください。

つづけて **ローカリゼーション**(日本語)を追加します。

- **表示名**:全セット解放(セット2〜10)
- **説明**:セット2から10までの1,800問を解放します。1回のお支払いで、以後ずっとご利用いただけます。

最後に **審査用のスクリーンショット**(課金アイテムごとに必須)を1枚アップロードします。
アプリのホーム画面で「すべて解放する ¥1,980」のボタンが写っているものを使ってください。

> 課金アイテムは、**それを含む最初のアプリのバージョンと一緒に審査**されます。
> アプリだけ先に提出すると課金アイテムが審査されないので、必ず同時に提出してください。

---

## 段階2:Sandbox テスターを作る

本物のお金を使わずに購入を試すためのアカウントです。

App Store Connect → **ユーザーとアクセス** → **Sandbox** → **テスター** → **+**

- **普段お使いの Apple ID とは別のメールアドレス**で作ってください(既存のIDは使えません)
- 受信できるアドレスなら何でも構いません(`+` を使ったエイリアスでも可)

作ったら iPhone 側で:**設定 → App Store → Sandbox アカウント** にサインインします。

## 段階3:実機でテストする

```bash
cd ~/Documents/toeic_test && git pull origin main
npm install
bash tools/build_app.sh && npx cap sync ios && npx cap open ios
```

Xcode から実機に入れて、**次の5つを必ず通してください。**

1. **セット1が最初から遊べる**(200問すべて。音声も解説も制限なし)
2. **セット2〜10に🔒が付いている**
3. **「すべて解放する ¥1,980」を押すと Apple の購入画面が出る** → 購入すると🔒が消える
4. **アプリを削除して入れ直し、「購入を復元する」で🔒が消える** ← ここが審査で必ず見られます
5. **機内モードにしても、購入済みなら🔒が付かない**

> Sandbox の購入では実際に課金されません。画面に「Sandbox環境」と出ます。

### うまくいかないとき

| 症状 | 原因 |
|---|---|
| 購入ボタンを押しても何も起きない | 製品IDの不一致、または有料App契約が未完了 |
| 価格が出ず「すべて解放する」だけ | ストアから商品情報を取れていない(段階0か段階1が未完了) |
| 「購入手続きを開始できませんでした」 | Sandbox アカウントにサインインしていない |

## 段階4:提出する

1. スクリーンショット(**1320 × 2868**)を3〜5枚
2. App Store Connect でアプリ情報を登録
   - 名前:`TOEIC® 総合問題集`(® を必ず付ける)
   - 価格:**無料**(課金アイテムで売るため)
   - カテゴリ:教育 / 年齢制限:4+
   - プライバシー:「データを収集しません」+ プライバシーポリシーのURL
   - **説明文に ETS の免責文を必ず入れる**
3. **課金アイテムを「提出準備完了」にして、アプリのバージョンに紐付ける**
4. Xcode で `Product` → `Archive` → `Distribute App` → アップロード
5. 審査に提出(審査メモは [APPSTORE_HOWTO.md](APPSTORE_HOWTO.md) の文面をそのまま使う)

### 審査メモに追記すること

4.2 対策の文面に加えて、次を足してください。

```
アプリ内課金について:
無料でセット1(200問)を全機能お試しいただけます。
「すべて解放する」から非消費型のApp内課金(製品ID:
com.eigoscoremogi.toeic.unlockall)をご購入いただくと、
セット2〜10(1,800問)が解放されます。
購入の復元はホーム画面の「購入を復元する」から行えます。
```

## 実装について(参考)

課金まわりは `js/iap.js` にまとまっています。設計で気をつけた点は3つです。

1. **オフラインで締め出さない** — 購入済みの状態は端末に記録し、起動時はまずそれを信じて解放します。ストアへの問い合わせは後から行い、通信できなくても記録は消しません。完全オフラインが売りのアプリで、機内モードで払った人が使えなくなるのは商品として壊れているためです。
2. **購入済みを自動で取り消さない** — ストアが「未所持」を返す理由には、返金だけでなく「Apple ID にサインインしていない」「一時的な障害」もあります。払った人を締め出す事故のほうが重いので、取り消しは行いません。
3. **価格を自前で書かない** — 表示する金額はストアから取得します。ハードコードすると、為替や地域によって実際の請求額とずれます。

買い切り(アプリ自体に値段を付ける)に戻す場合は、`tools/build_app.sh` の
`unlockAll` を `true` にして `iap` の項目を消すだけです。
