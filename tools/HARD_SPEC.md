# 難易度調整 作業仕様(リーディング)

あなたは市販レベル(有料販売)のTOEIC模試の作問担当。**指定された1つのデータファイルだけ**を、狙いのレベルに合わせて書き換える。

現状は「本番より明らかに易しい」と著者(TOEIC 950点・R満点)から指摘されている。ただし**上げすぎも禁止**。狙うのは次のレベル感。

## 狙うレベル(最重要)

**基準は『公式TOEIC Listening & Reading 問題集』(ETS)。**市販の『TOEIC 700点クラス向け問題集』に出てくるような問題を多めに配置する。

30問なら、おおよそこの配分にする(Part 6/7 も同じ比率感で)。

1. **やさしめ(600点前後で解ける):全体の 25%** — 本番にも必ずある平易な問題。ゼロにしない。
2. **標準(700点クラスの問題集レベル):全体の 60%** — ここが中心。
3. **難問(900点保持者でも落としうる):全体の 15%** — 各パートに数問だけ。

## 難問の作り方(ここを間違えないこと)

**900点レベルが落とすのは『語彙が難しい問題』ではない。**難単語を並べるのは方向が違うので絶対にやらない。落とすのは次のようなもの。

- **関係詞の使い方が難しい問題** — `whose` / 前置詞+関係代名詞(`in which` / `for which`)/ 関係副詞と関係代名詞の使い分け / `what` と `that` の区別 / 二重限定 / 関係詞の非制限用法
- **構造がつかみにくい問題** — 挿入句や同格で主語と動詞が大きく離れる / 分詞構文の意味上の主語 / 倒置(否定語句の文頭、`so`/`neither`)/ 相関接続詞(`not only ... but also`)の並列関係
- **場面がイメージしづらい問題** — 何を指しているのか、誰の行為なのかを読み取らないと決まらない(指示語・代名詞の対応、省略された語の補完)
- **一見どれも入りそうな問題** — 4つとも文法的には成立するが、文脈上1つしか成り立たない

語彙で難しくする場合も、**TOEICに実際に出る業務語彙の範囲内**にとどめる。学術的な難単語、日常業務で使わない単語は使わない。「知っていれば一瞬、知らなければ手も足も出ない」タイプの語彙問題は1〜2問まで。

## 手順
1. `/workspace/toeic_test/tools/AGENT_SPEC.md` を Read して、そのパートの必須仕様(問題数・形式)を確認する。
2. `/workspace/toeic_test/tools/DEDUP_BANLIST.md` を Read して、他セットと題材が重複しないようにする。
3. 対象ファイルを Read する。
4. **難度だけを調整して書き換える。**下の「守ること」を厳守。
5. `node --check <対象ファイル>` で構文確認する。
6. 最終メッセージは短く:やさしめ/標準/難問の内訳と、難問にした箇所の狙いを5行以内で。ファイル本文は貼らない。

## 守ること(絶対)
- **問題数・文書数・id を一切変えない。**Part 5=30問、Part 6=4文書×4問、Part 7=15文書54問(内訳も現状維持)。id は既存のものをそのまま使う。
- `answer` は選択肢配列の添字(0=A)。差し替えたら必ず添字を合わせ直す。
- **正解位置を均等に散らす。**A/B/C/D がおおよそ同数になるようにする。
- 日本語の `explanation`(解説)と `translation`(訳)を必ず書き直す。強調は『』を使い、Markdownの `**` は絶対に使わない。
- 解説の中で選択肢を指す記号(A)(B)(C)(D)は、必ず実際の配列位置と一致させること。
- 【最重要】1つの文書に複数の設問が付く場合、**ある設問の答えが他の設問の文・選択肢から推測できてはならない。**書き換え後に自分で全設問を読み返して確認する。
- 固有名詞・場面が他セットと重複しないこと。

## パート別の具体策

### Part 5(短文穴埋め・30問)
- 出題比率は本番どおり:語彙10問前後、品詞・語形6問、動詞の形(態・時制・一致)5問、前置詞/接続詞/接続副詞5問、関係詞・代名詞3問、比較・仮定法・倒置など1問。
- **標準レベル(18問前後)**は、文が1〜2行あり、空所の前後だけでなく文全体を見れば確実に解けるもの。
- **難問(4〜5問)**は上の「難問の作り方」から選ぶ。関係詞2問、構造把握1〜2問、文脈依存1問が目安。
- **やさしめ(7〜8問)**は、空所の前後だけで解ける品詞問題や基本的な前置詞。本番にもあるので必ず残す。

### Part 6(長文穴埋め・4文書16問)
- 空所の半分程度を、**その文だけでは決められず前後の文脈が要る**ものにする(時制の一貫性、指示語の対応、接続副詞の論理関係)。
- 文挿入問題(各文書1問)のうち1問は、代名詞や指示語の対応で決まる難しめのものにする。残りは標準。
- 文書は本番並みの長さ(110〜160語)。難単語を増やすのではなく、情報のつながりで読ませる。

### Part 7(読解・15文書54問)
- **本文の表現をそのまま含む選択肢を正解にしない。**正解は本文の言い換え(パラフレーズ)にする。逆に、本文の語句をそのまま含む誤答を1つ入れる。これが本番との一番大きな差。
- 推論問題(What is suggested / implied / most likely)を全54問中10問前後に。
- NOT問題を2〜3問、意図問題を2問、語彙問題(the word "X" in paragraph N is closest in meaning to)を3問。語彙問題の語は**基本語の多義**(address / figure / hold / draw / issue など)にする。難単語にしない。
- **【最重要】ダブル・トリプルの作り込み。**ここがTOEICの難しさであり面白さの中心なので、最も力を入れる。
  - **ダブル(5問)のうち2問以上**、**トリプル(5問)のうち3問以上**を、2つ以上の文書を突き合わせないと解けない設問にする。
  - 突き合わせの型を使う:片方に「条件・規定・料金表・日程」、もう片方に「個別の事情・申込内容・変更依頼」を書き、両方を照合して初めて答えが決まる形にする(例: 料金表の区分 × 申込者の人数 → 支払額 / 締切日 × 送信日 → 間に合うか / 条件一覧 × 応募者の経歴 → 該当する職種)。
  - **トリプルは3文書すべてを読まないと全体像がつながらない構成にする。**1つ目だけ、2つ目だけを読んでも状況が把握できないようにし、3文書目で初めて事情が判明する設問を必ず1問入れる(例: 日程表 → 変更を知らせるメール → その変更を受けた返信、という時系列で、最終的にどうなったかは3つ目を読まないと決まらない)。
  - 文書間をつなぐ手がかり(人名・部署名・注文番号・日付・座席番号など)を各文書に散らし、**同じ語をそのまま繰り返さず言い換える**。片方が "the Springfield branch"、もう片方が "our northern location" のように、対応関係に気づくこと自体を問う。
  - 1つの文書だけで答えが出てしまう設問ばかりにしない。
- 文書は本番並みの長さ(シングル150〜230語、ダブル・トリプルは各文書120〜180語)。
- 難問(全体の15%程度)は、**複数箇所の情報を組み合わせないと決まらない**もの、**紛らわしい2択に絞ってから細部で決める**ものにする。

## やってはいけないこと
- 難単語・学術語彙を並べて難しくすること。**本番の文章は平易で自然な業務英語**。
- 英語として不自然な文、回りくどいだけの文を作ること。
- 正解が2つあり得る、または正解が無い問題を作ること。書き換えたら必ず自分で解き直して1つに定まることを確認する。
- 問題数・id・ファイル構造を変えること。
- 全体を難問だらけにすること。**やさしめ25% / 標準60% / 難問15%** を守る。
