# note で売る手順

アプリは1つのURLで公開し、**セット1は無料・セット2〜10は合言葉で解放**する仕組みになっています。
note の有料記事に合言葉を書いて売ります。決済も入金も note がやってくれるので、あなたが用意するのは記事だけです。

商品は2ラインあります。

1. **標準(セット2〜6)** — 公式問題集〜700点クラス中心。既存の5セット。
2. **上級(セット7〜10)** — 800〜900点を狙う人向け。やさしい問題を入れず、関係詞・構造・文書の突き合わせで難度を上げた4セット。

## 手順

### 1. アプリを公開する(すでに公開済み)

https://toeic.bridge-ai-tokyo.com/

#### 記事を書いたら、購入ページのURLをアプリに登録する

アプリのホームには「セット1は無料 / セット2以降は有料」と出ますが、
**買える場所へのリンクは、URLを登録するまで出ません**(リンク切れを出さないため)。

note の記事を公開したら、`js/app.js` の次の行に記事のURLを入れてください。

```js
var SHOP_URL = "";   // ← ここに note の記事URLを入れる
```

例:

```js
var SHOP_URL = "https://note.com/あなたのID/n/xxxxxxxx";
```

入れると、ホームの説明の下と、合言葉ボタンの横に『セットを購入する →』が出ます。
**これが無いと、買いたい人が買い方にたどり着けません。**忘れずに登録してください。

> アプリ版(App Store)ではこのリンクは自動的に出ません。
> ガイドライン 3.1.1 で、アプリ内の機能解放を外部の購入手段へ誘導することが
> 禁止されているためです(出すとリジェクトされます)。

### 2. note で記事を作る

セットごとに1本、まとめ買い用に1本。標準6本+上級5本=合計11本です。まずは1本(セット2)から始めても構いません。

**無料部分に書くこと**
- どんな問題集か(本番と同じ200問構成、全問に日本語解説と全訳、リスニング音声つき)
- 画面のスクリーンショット
- **「セット1は無料で全部解けます」+ アプリのURL** ← これが一番効きます
- あなたの実績(独学3年で資格30以上、TOEIC 950・R満点)

**有料部分に書くこと**
- アプリのURL(もう一度)
- 合言葉
- 使い方3行(URLを開く → セット2のタブを押す → 合言葉を入れる)

### 3. 価格を決める

1セット300円、5セットまとめ1,500円あたりが目安です。note の手数料は売上の15%前後(決済手数料+プラットフォーム利用料)。300円なら手取り255円前後です。

上級(セット7〜10)は作問の密度が高いので、1セット400円・4セットまとめ1,400円のように少し上げても通ります。ただし**最初は標準と同じ300円で出し、レビューが付いてから上げる**ほうが売れ始めが早いです。値下げはしない方針なので、迷ったら安いほうから始めてください。

### 4. 売ったあとも改良できます

**購入者は次にURLを開いた瞬間、最新版になります。**買い直しは不要です。
「購入後の改良もすべて無料で反映されます」と書けるので、これは売り文句になります。

## 合言葉を変えたいとき

```bash
node tools/make_code.js 好きな合言葉
```

出てきた値を `js/app.js` の `CODE_HASHES` に貼り、対応するセットidを書きます。

```js
var CODE_HASHES = {
  "出てきた値": ["s2"],
  ...
};
```

## 無料で公開するセットを変えたいとき

`js/app.js` の次の行を書き換えます。

```js
var FREE_SETS = { s1: true };        // セット1だけ無料
var FREE_SETS = { s1: true, s2: true };  // セット2も無料にする場合
```

## 正直な限界

- 合言葉を人に教えられたら、その人も使えます。ブラウザの開発者ツールを開けば問題文も見えます
- これは note の有料記事がコピペできるのと同じ話です。300円の商品にサーバーとログインを用意するのは費用対効果が合いません
- 売れ行きが大きくなってから、サーバー方式に移行すれば十分です
