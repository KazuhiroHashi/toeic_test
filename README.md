# TOEIC 総合問題集

TOEIC L&R 形式のオリジナル問題を、ブラウザだけで練習できる静的Webアプリ。インストール・ビルド不要で、スマホでも動きます。

**全10セット・2,000問**(1セット=本番と同じ200問)。

- **セット1〜6(標準)** — 公式問題集〜700点クラス中心。セット1は無料
- **セット7〜10(上級)** — 800〜900点を狙う人向け。やさしい問題を入れず、関係詞・構文・文書の突き合わせで難度を上げています

## 収録内容(1セットあたり計200問=本番と同じ問題数)

- Part 1 写真描写:6問 ✅(モノクロ写真を使用。1200px幅のグレースケールJPEGに圧縮済み(1枚約150KB)でモバイル回線でも待たされない。本番同様、説明文は印刷されず音声のみ。進行形/状態受動態/put on・wearの区別など頻出パターンを配置)
- Part 2 応答問題:25問 ✅(前半15問は標準タイプ、16問目以降は近年増加中の間接応答・変化球タイプ。質問と応答は本番同様、別話者・男女別の声)
- Part 3 会話問題:13会話39問 ✅(3人の会話×2、図表問題×2、意図問題を含む)
- Part 4 説明文問題:10トーク30問 ✅(図表問題×2を含む。電話メッセージ・アナウンス・広告・会議・スピーチ・交通情報など本番の文脈を網羅)
- Part 5 短文穴埋め:30問 ✅(基礎〜上級ミックスで、語彙問題約3割+品詞・動詞形・前置詞/接続詞・仮定法倒置・分詞構文など本番の出題比率を反映)
- Part 6 長文穴埋め:4文書16問 ✅(各文書に文挿入問題を含む)
- Part 7 読解問題:54問 ✅(シングルパッセージ10文書29問+ダブルパッセージ2セット10問+トリプルパッセージ3セット15問。クロスリファレンス問題・計算型問題・意図問題・語彙問題・NOT問題を含む)
- 4分の1模試:上記から本番に近い比率で50問を抽出(毎回同じ問題数)

図表問題(Look at the graphic.)では、本番同様に図表が画面に表示され、音声と突き合わせて解答します。

## セット7〜10(上級)の作り方

セット1〜6より一段上の難度を狙っています。方針は [tools/HARD2_SPEC.md](tools/HARD2_SPEC.md) にまとめてあります。

- 難度の配分は 標準30% / 上級50% / 難問20%。**やさしめ(600点で解ける)問題は入れない**
- **難単語を並べて難しくすることは禁止。**900点が落とすのは語彙力ではないため、関係詞(`whose` / `in which` / 連鎖関係詞)、構造把握(挿入句・倒置・分詞構文の意味上の主語)、指示語の対応、情報の突き合わせ量で難度を上げています
- Part 7 は**ダブル5問中3問以上・トリプル5問中4問以上**を複数文書の突き合わせ問題に。トリプルは3文書すべてを読まないと全体像がつながらない構成にし、3文書目で初めて事情が判明する設問を各セット2〜3問配置
- 文書間の手がかりは同じ語を繰り返さず言い換える(`the smallest of the three stands` ↔ `3 m × 3 m` など)。対応関係に気づくこと自体を問う

## 品質の検査

問題を追加・変更したら次を実行します(`sync.sh` に組み込み済み)。

```bash
node tools/check_integrity.js   # 問題数・id重複・正解の範囲・解説/訳の有無・記号ずれ
node tools/check_duplicates.js  # セット間で題材が重複していないか
node tools/check_leak.js        # ある設問の答えが別の設問から割れていないか
node tools/check_part7_order.js # Part 7 の構成が本番どおりか(2,2,2,2,3,3,3,4,4,4)
node tools/check_labels.js      # 解説の(A)(B)(C)(D)が実際の選択肢と合っているか
node tools/check_mock.js        # 4分の1模試が必ず50問になるか
node tools/check_audio.js       # 出題に必要な音声がそろっているか
```

`check_leak.js` は、著者の指摘した「Q1が『どこにいる?』(答え=ホテル)なのに、Q2の選択肢に reservation が出ていて割れてしまう」型を検出します。場所・人物・業種を特定する設問だけを対象にしているので、話題語の自然な再出現は拾いません。

全問題に日本語の解説と全訳付き。

### 録音音声の生成(edge-tts)

リスニング音声は録音ファイル(mp3)を同梱し、全端末で同じ声(米・英・豪・加のニューラル音声9声)で再生される。全10セット合計で 4,252クリップ・約350分・約125MB。

手順の詳細 → **[tools/AUDIO_HOWTO.md](tools/AUDIO_HOWTO.md)**(Mac のターミナルで実行。無料・APIキー不要)

問題を追加・変更したら `node tools/build_audio_manifest.js` で一覧を作り直してから再生成する。**録音が無い問題は音声合成で代替せず、エラーになる**ので、push の前に必ず `node tools/check_audio.js` で確認する。

### 音声(リスニング)の仕組み

**リスニングは必ず同梱の録音音声(mp3)で再生します。端末の音声合成は使いません。**
端末ごとに声が変わったり発音が不安定になったりするため、合成音声への切り替えは廃止しました。
音声が読み込めない場合は、代替再生をせずエラーを表示します。

- 声は米・英・豪・加の8名。問題ごとに4カ国をローテーションして配役します
- **ナレーター(問題番号・導入文・設問読み上げ)は女性(en-US-MichelleNeural)固定**。登場人物とは別の専用の声で、読み上げ速度も -8% にして進行役と分かるようにしています
- 記号(A. B. C. D.)は言い切れる米国の2声(Guy / Jenny)で読み、本文の話者と性別だけ合わせます
- 本番同様、ナレーターが「Questions 32 through 34 refer to the following conversation.」という導入文を読んでから会話が始まります
- iOS では本体のマナーモードがオンだと音が鳴りません(イヤホン接続時は問題なし)

**push する前に必ず実行してください。**1つでも音声が欠けると、その問題は再生できません。

```bash
node tools/check_audio.js
```

## 機能

- **リスニング模試(Part 1-4)**:本番と同じ100問を通しで解答。画面が出ると音声が自動で再生される(時間制限なし)
- **リーディング模試(Part 5-7)**:本番と同じ100問・制限時間75分のカウントダウン付き
- **4分の1模試(50問)**:本番200問の比率に近づけて全パートから抜き出す。20〜25分
  - Part 1:1問 / Part 2:6問 / Part 3:9問(会話3つ)/ Part 4:9問(トーク3つ)/ Part 5:7問 / Part 6:4問(文書1つ)/ Part 7:14問(ダブル1セット+シングル)
  - **リスニング25問・リーディング25問**は本番の 50:50 と完全に一致。**毎回必ず同じ問題数**
  - パート単位では本番比率と完全一致にはできない。Part 3・Part 4 は会話/トーク1つ=3問の単位でしか取れず、200問の4分の1(Part 3=9.75問、Part 4=7.5問)を整数にできないため。いちばんずれるのが Part 4 で、本番15%に対し18%(+1.5問)。この配分は、取りうる組み合わせをすべて調べたうえで**ずれの合計が最小**になるものを選んでいる(`tools/check_mock.js` が50問固定を保証)
- パート別練習
- 本番と同じ進め方:解答中は選んだ記号が印になるだけで、正誤・解説は最後にまとめて表示(前の問題に戻って選び直せる)
- 問題を選んで解くモード(パートごとの問題一覧から好きな問題だけを選択して挑戦。結果画面から同じ選択で再挑戦可能。選択モードの成績は自己ベストには含めない)
- **解答の途中保存**:模試の途中で閉じても、次に開いたときホーム画面から続きを再開できる(選んだ答えと残り時間も復元)
- **予想スコア換算**:結果画面にリスニング/リーディング/合計の予想スコア(5点刻み)を表示。20問以上解いたセクションだけが対象で、参考値である旨を明記
- 結果画面で全問の解答・解説・全訳・スクリプトを確認(間違えた問題だけの表示に切替可)
- リスニングはスクリプト非表示で出題 → 解答後にスクリプトと全訳を公開
- Part 2 は本番同様、選択肢を見せずに音声のみで出題
- 問題番号は本番の通し番号(Part 1:1-6 / Part 2:7-31 / Part 3:32-70 / Part 4:71-100 / Part 5:101-130 / Part 6:131-146 / Part 7:147-200)
- Part 6/7 は本番同様、日本語の設問文を出さず「Questions 131-134 refer to the following e-mail.」形式の見出しを表示
- パートごとの自己ベスト・挑戦回数を保存(ブラウザの localStorage、端末内のみ)
- セット1は無料、セット2〜10は合言葉で解放(販売用。合言葉はソースに書かず照合値のみを保持)。セット7〜10は上級(800〜900点向け)

## 問題の追加方法

問題データはセット1が `data/part1.js`〜`data/part7.js`、セット2〜10が `data/setK/part1.js`〜`part7.js` に分かれています。各ファイル内のオブジェクトを同じ形式でコピーして追記するだけで、アプリに自動的に反映されます。`answer` は選択肢配列の添字(0 = A)です。

新しいセットは `part7.js` までそろって初めてアプリの選択肢に出ます(作りかけのセットが表示されないようにするため)。

作問ルール(Part 3/4 など1つの音声に複数設問が付く場合):**ある設問の答えが、他の設問の文や選択肢から推測できてはならない**。例えば Q1 が「どこにいる?」(答え:ホテル)なら、Q2・Q3 の文・選択肢に hotel / reservation などの語を入れない。場所・目的・主題を問う設問と、それを前提にした語を含む設問を同じセットに共存させないこと。

## 注意事項

- 収録している問題はすべてオリジナルに作成したものです。
- TOEIC®はエデュケーション・テスティング・サービス(ETS)の登録商標です。この製品はETSの検討を受けまたはその承認を得たものではありません(アプリのフッターにも常時表示しています)。
- リスニングは同梱の録音音声(mp3)のみで再生されます。端末の音声合成は使いません。
