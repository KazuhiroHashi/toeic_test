# TOEIC 総合問題集

TOEIC L&R 形式のオリジナル問題を、ブラウザだけで練習できる静的Webアプリ。インストール・ビルド不要で、スマホでも動きます。

## 収録内容(計200問=本番と同じ問題数)

- Part 1 写真描写:6問 ✅(モノクロ写真を使用。1200px幅のグレースケールJPEGに圧縮済み(1枚約150KB)でモバイル回線でも待たされない。本番同様、説明文は印刷されず音声のみ。進行形/状態受動態/put on・wearの区別など頻出パターンを配置)
- Part 2 応答問題:25問 ✅(前半15問は標準タイプ、16問目以降は近年増加中の間接応答・変化球タイプ。質問と応答は本番同様、別話者・男女別の声)
- Part 3 会話問題:13会話39問 ✅(3人の会話×2、図表問題×2、意図問題を含む)
- Part 4 説明文問題:10トーク30問 ✅(図表問題×2を含む。電話メッセージ・アナウンス・広告・会議・スピーチ・交通情報など本番の文脈を網羅)
- Part 5 短文穴埋め:30問 ✅(基礎〜上級ミックスで、語彙問題約3割+品詞・動詞形・前置詞/接続詞・仮定法倒置・分詞構文など本番の出題比率を反映)
- Part 6 長文穴埋め:4文書16問 ✅(各文書に文挿入問題を含む)
- Part 7 読解問題:54問 ✅(シングルパッセージ10文書29問+ダブルパッセージ2セット10問+トリプルパッセージ3セット15問。クロスリファレンス問題・計算型問題・意図問題・語彙問題・NOT問題を含む)
- ミニ模試:上記から約30問をランダム出題

図表問題(Look at the graphic.)では、本番同様に図表が画面に表示され、音声と突き合わせて解答します。

## ロードマップ:本番と同じ200問構成へ

実際のTOEIC L&Rと同じ問題数(リスニング100問+リーディング100問、計200問)を達成。

1. Part 1 写真描写:6問 ✅(自作イラスト。実写写真への差し替えは将来の改善候補)
2. Part 2 応答問題:25問 ✅
3. Part 3 会話問題:13会話39問 ✅
4. Part 4 説明文問題:10トーク30問 ✅
5. Part 5 短文穴埋め:30問 ✅
6. Part 6 長文穴埋め:4文書16問 ✅
7. Part 7 読解問題:54問 ✅

次のステップ:本番と同じ2時間(リスニング約45分+リーディング75分)のタイマー付きフル模試モードの追加。

### 音声ファイルの同梱(検討中)

端末やブラウザに依存せず全員が同じ音で聞けるよう、リスニング音声を録音ファイル(mp3)としてアプリに同梱する構想がある。高品質なニューラル音声(米・英・豪・加の男女8名+ナレーター)での生成を予定しているが、生成にはTTSサービスへのネットワークアクセスが必要(現在の開発環境ではブロックされているため未実施)。同梱後は、音声ファイルがある問題は録音を再生し、無い問題は従来どおり音声合成にフォールバックする設計とする。

全問題に日本語の解説と全訳付き。

### 録音音声の生成(edge-tts)

リスニング音声は録音ファイル(mp3)を同梱でき、あれば全端末で同じ声(米・英・豪・加のニューラル音声9声)で再生される。全6セット合計で 1,928クリップ・約160分・約56MB。

手順の詳細 → **[tools/AUDIO_HOWTO.md](tools/AUDIO_HOWTO.md)**(Mac のターミナルで実行。無料・APIキー不要)

問題を追加・変更したら `node tools/build_audio_manifest.js` で一覧を作り直してから再生成する。録音が無い問題は自動的にブラウザの音声合成へフォールバックする。

### 音声(リスニング)の仕組み

**リスニングは必ず同梱の録音音声(mp3)で再生します。端末の音声合成は使いません。**
端末ごとに声が変わったり発音が不安定になったりするため、合成音声への切り替えは廃止しました。
音声が読み込めない場合は、代替再生をせずエラーを表示します。

- 声は米・英・豪・加の8名。問題ごとに4カ国をローテーションして配役します
- **ナレーター(問題番号・導入文・設問読み上げ)は女性(en-US-MichelleNeural)固定**。登場人物とは別の専用の声で、読み上げ速度も -8% にして進行役と分かるようにしています
- 記号(A. B. C. D.)は言い切れる米国の2声(Guy / Jenny)で読み、本文の話者と性別だけ合わせます
- 本番同様、ナレーターが「Questions 32 through 34 refer to the following conversation.」という導入文を読んでから会話が始まります
- iOS では本体のマナーモードがオンだと音が鳴りません(イヤホン接続時は問題なし)

**push する前に必ず実行してください。**1つでも音声が欠けると、その問題は再生できません。

```bash
node tools/check_audio.js
```

## 使い方

### ローカルで開く

`index.html` をブラウザで開くだけで動きます(サーバー不要)。

### GitHub Pages で公開する

1. リポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/toeic_test/` で公開されます

## 機能

- パート別練習 / ミニ模試 / リーディング模試(Part 5-7・100問・制限時間75分)
- 本番と同じ進め方:解答中は選んだ記号が印になるだけで、正誤・解説は最後にまとめて表示(前の問題に戻って選び直せる)
- 問題を選んで解くモード(パートごとの問題一覧から好きな問題だけを選択して挑戦。結果画面から同じ選択で再挑戦可能。選択モードの成績は自己ベストには含めない)
- 結果画面で全問の解答・解説・全訳・スクリプトを確認(間違えた問題だけの表示に切替可)
- リスニングはスクリプト非表示で出題 → 解答後にスクリプトと全訳を公開
- Part 2 は本番同様、選択肢を見せずに音声のみで出題
- 問題番号は本番の通し番号(Part 1:1-6 / Part 2:7-31 / Part 3:32-70 / Part 4:71-100 / Part 5:101-130 / Part 6:131-146 / Part 7:147-200)
- Part 6/7 は本番同様、日本語の設問文を出さず「Questions 131-134 refer to the following e-mail.」形式の見出しを表示
- パートごとの自己ベスト・挑戦回数を保存(ブラウザの localStorage、端末内のみ)
- セット1は無料、セット2〜6は合言葉で解放(販売用。合言葉はソースに書かず照合値のみを保持)

## 問題の追加方法

問題データは `data/part2.js`〜`data/part7.js` に分かれています。各ファイル内のオブジェクトを同じ形式でコピーして追記するだけで、アプリに自動的に反映されます。`answer` は選択肢配列の添字(0 = A)です。

作問ルール(Part 3/4 など1つの音声に複数設問が付く場合):**ある設問の答えが、他の設問の文や選択肢から推測できてはならない**。例えば Q1 が「どこにいる?」(答え:ホテル)なら、Q2・Q3 の文・選択肢に hotel / reservation などの語を入れない。場所・目的・主題を問う設問と、それを前提にした語を含む設問を同じセットに共存させないこと。
